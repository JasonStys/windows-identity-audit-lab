# Native Windows identity workbench validation

Created by Jason Stys. Candidate version 1.1.0; local observations on 10–11 November 2026. [Practical usage and boundaries](../native-workbench.md).

## What changed and why

The real offline snapshot audit, observed direct-membership comparison and nested recertification queue now have graphical file/policy/time controls. Users can select their supported authorized inputs, inspect original SID/path evidence, filter literal records, export exact files and reopen durable saved analyses. Prepared fictional scenarios fill these ordinary controls in the full application; they do not run or approve themselves. Edits clear permission acknowledgement.

The current findings remain visible when a recertification owner queue is empty. Incomplete group evidence retains NOT_OBSERVED_UNVERIFIED rather than claiming revocation or a clean complete audit. Changed representative paths, added exposures and merely newly observed direct edges remain distinct. Status text explicitly says INCOMPLETE evidence — review required. No GUI path imports PowerShell, enumerates a host or changes accounts/groups.

## Runtime and CI boundary

The package checks the actual Python DLL identity and gathers Python, real Tcl/Tk 9 zipfs and applicable PyInstaller runtime notices. It needs no user-installed Python/Node, shell commands or account/password. This is a Windows portable executable, not an installer, Authenticode-signed app or cross-platform binary.

All original four OS/Python quality, security and separately authorized disposable-runner PowerShell/collector-contract lanes remain. A new exact Python 3.14.10 Windows lane audits the native graph, builds and exercises the actual EXE. Packages, account snapshots and test profiles are not uploaded and no Actions cache is created. Local observations above are candidate measurements with source_dirty=true; they do not establish later hosted outcomes or publication. The genuine POSIX FIFO case is required in the hosted POSIX lanes and must not be called a local Windows pass.

## Limits

Membership exposure is not effective access, complete Windows authorization, authenticated approval or a compliance/security certification. Owner-local plaintext SQLite and an exclusive process lock are not protection against another process running as the OS owner. Retention is 20 analyses/128 MiB payload; full original files remain exportable even when the table caps visible rows. No live collection, account action, external lookup/upload, installed user data or Docker was touched. Original Office publications retain their historical source/date meaning.
